`bind_tenant_realm/3` can also return `{:error, :tenant_not_active}` (tested). (c) unknown `admin_*`
keys go to `ignored_fields` (to pin). (d) double: answers `:not_found` for `unknown*`, `:unreachable`
for `unreachable*`. (e) probe scheme case-insensitive, unknown scheme => `:unreachable` (to test).

the accessor read the same config); planned seam: a `[:letflow, :repo, :query]` telemetry handler that
flips the pin via `Application.put_env` on the first `onboarding_registry` query (issued after the
gate, before the prefix check), restored by `PlatformTenantFixture`'s `on_exit`.
