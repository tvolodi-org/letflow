## Not asserted here (stated, not hidden)

* The design's T-Z2 HTTP form (a 409 from `scope_tenant_admin` over HTTP) is unreachable by the
  coordinator ruling; only the function-level guard test and the "allowed" HTTP cases exist.
* T-A9 as a command (`mix letflow.permission_matrix --check`) is a CI static step, not an ExUnit
  case: the policy-key test pins that no permission atom was added and
  `permission_matrix_test.exs` is the byte-level golden check.
* AC 22 (shadow counters) is 2b.
