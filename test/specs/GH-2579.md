# GH #2579: inventory and flag non-expiring PLATFORM_ADMIN API tokens, with a documented revoke and re-mint

Design: `state/tasks/T-0144/design.md` (D1-D9). Code: `lib/letflow/identity/platform_admin_tokens.ex` (`inventory/1`, `reissue/4`), `lib/letflow/identity/api_token.ex` (`non_expiring_platform_admin?/1`), `lib/letflow/identity.ex` (`cause` option on `mint_token/4` and `revoke_token/2`, `platform_admin_token_max_ttl_days/0` made public), `lib/letflow/identity/token_preconditions.ex` (predicate reuse), `lib/letflow/api/token_view.ex` (`no_expiry` key), `lib/letflow/release.ex` (`platform_admin_token_inventory/1`, `reissue_platform_admin_token/4`), `docs/runbooks/platform-admin-token-reissue.md`.

## Behaviour under test

- Inventory: lists live, non-expiring PLATFORM_ADMIN tokens of one tenant schema, with owner, issuer (NULL = legacy), created_at and last_used_at. It reads no `token_hash` and no `name`.
- Reissue (one token, explicit): refuses before any write unless the token is live, non-expiring PLATFORM_ADMIN, the operator is an active PLATFORM_ADMIN of the tenant, and `cause`, `days` and the plaintext path are valid. Creates the plaintext file exclusively before minting. Mints a replacement for the owner with an expiry inside the cap, writes its value to the file, then revokes the old token. Both audit entries carry `cause`, the operator as `actor_id` and one `trace_id`.
- Token list: each item carries `no_expiry`, true only for a non-expiring PLATFORM_ADMIN token.
