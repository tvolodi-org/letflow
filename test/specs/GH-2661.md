# Test spec: GH #2661 (REQ-473) org module skeleton

Files: `test/letflow/modules/org/{entity_definitions,pack_drift,registration,install}_test.exs`.
Real Postgres, real routers (`Letflow.Routers.TenantModules`, `Letflow.Routers.Entities`), real
`Records.create_record/3` on the owner path (`ManagedTypes.owner_for!(Letflow.Modules.Org)`). No mocks.

## Criterion to test map
