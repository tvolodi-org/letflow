# REQ-497 PR 1a test spec: role_scope_grants table, backfill, binding writers (GH #2533)

Design: `lib/letflow/design/req497-1a-role-scope-grants-table-backfill-writers.md` (Revision 1),
section 6 (T-M*, T-C*, T-W*, T-B*, T-N* ids are the design's). Decision 0051 D1, D3, D8.
Scope: REQ-497 acceptance criteria [1a] AC1-AC4 and AC17 for 1a only.

Pre-fix note: the table, the core module, the writer calls and the sweep did not exist before this
change, so "fails on the pre-fix code" is trivially true and proves nothing. Coverage is argued per
test below ("what it would catch"), and mutants are listed (and, where the host allowed a run,
measured) in the step-05 handoff
`handoffs/WF02-GH2533-SCOPE-GRANTS-20261015/step-05-test-designer-1a.json`.

All four new test files are `async: false`: they migrate down/up, install triggers (raw DDL),
commit writes in dedicated `TenantFixture.provisioned_tenant!/1` schemas (never pooled), or sweep
every registration. Sweep tests (`RoleBackfill.run/0`, `TenantAdminMigration.run/1`,
`Backfill.run/1`, the mix task) isolate the registrations to their own tenants first
(`TenantAdminMigrationFixture.isolate_registrations!/1`, restored in `on_exit`). No test waits on
time; there is no sleep and no unseeded randomness.
