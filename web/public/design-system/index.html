03 — Space and size

A 4px grid, with fixed sizes for dense parts.

Spacing is the front door scale. The platform adds control, row and tree sizes so every table and form lines up.

04 — Paper and Night

Same components, two themes.

Set data-theme="dark" on any element, or follow the system setting. The side nav stays night in both.

09 — Tabs

Sections of one record, with counts.

Tabs switch views of the same record. They scroll sideways on phones instead of wrapping.

10 — Tree view

Hierarchies read as lines.

Each level indents by tree-indent (20px) with a hairline guide. Arrow keys move, Right opens, Left closes, Enter selects. Names cut with an ellipsis; the full path is in the detail header.

14 — Dialog

One question, one decision.

Title is the question, the body says what happens, the confirm button repeats the verb. Destructive confirms use the danger button. Escape closes; focus returns to the button that opened it.

18 — Tenant brand

A tenant can replace the teal, nothing else.

The tenant colour is applied through --tenant-current and its three partners. Paper, ink, status colours and ember stay Letflow. The sample uses a blue tenant (checked 6.3:1 on paper-raised).
