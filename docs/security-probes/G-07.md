# G-07 — cursor/codec property probe

Gap **G-07** of the security coverage map (`docs/security-coverage.md` §4,
lab repository): *"Cursor/codec property tests over arbitrary legal ids,
separators, legacy prefixes, expiry and exact-once multi-page traversal,
generated from the cursor-builder inventory."*

The defect class it would have caught: **T-2571** — a colon-bearing
`service_id` shifted the cursor's slots, and a legacy cursor decoded into the
wrong values, allowing repeated/looping pages.

## What the probe is

A mechanical, deterministic, model-free ExUnit probe. It generates its cases
from an inventory of the product's cursor builders
(`test/support/cursor_builder_inventory.ex`), so a new cursor builder is
covered the moment the inventory names it — and the inventory itself is
anchored in the tree, so an entry that drifts fails the probe.

| file | what it holds | tag | declared cost |
|---|---|---|---|
| `test/support/cursor_builder_inventory.ex` | the inventory, the tree scan, the seeded broken decoder | — | — |
| `test/letflow/security_probe/g07_cursor_codec_probe_test.exs` | the pure codec properties (no database) | `:security_probe`, `:unit` | `probe_cost_s: 5` |
| `test/letflow/security_probe/g07_cursor_traversal_probe_test.exs` | the exact-once multi-page traversal (real Postgres) | `:security_probe` | `probe_cost_s: 15` |

The enforcement is not "the probe files are ordinary test files" (that only
runs them when they change): the pure half carries `@moduletag :unit`, which
puts it in the team runner's unit tier (`mix test --only unit`, run on every
non-rework backend change), and both files are in the product's bounded-CI
safety set (`scripts/ci_select_tests.py`, `STANDARD_SECURITY_PROBE_TESTS`),
which makes them mandatory on every bounded run. The tag `:security_probe` and
the per-file cost `@moduletag probe_cost_s: N` say so; the operator's `lf.sh`
hook can select the tagged set once it exists.

Run it:

```sh
MIX_TEST_PARTITION=<task> mix test --only security_probe
```

Total wall time of the tagged set on this host: **under 10 s** (pure half
≈ 4 s, traversal half ≈ 1 s), well inside the 5-minute budget of the tagged
`security_probe` set.

Slot vocabulary: `mint` (the cursor's own issue time), `mint_dt` (a timestamp
that is both the mint time and the seek key — the pre-issue-time cursor
generations), `dt`, `int`, `uuid`, `string` (free: may contain `:`), `rank_id`
(the machine-built `"<rank>|<uuid>"` composite of the definitions search
cursor — constrained, so it never contains `:`).

### Why a free string must be the last slot

`Letflow.Api.Pagination.decode_seek_parts/3` splits the payload with
`String.split(rest, ":", parts: slots)`: only the LAST part keeps the colons
that follow it. A free string in an earlier slot is therefore truncated at its
first colon and every slot behind it shifts — the T-2571 defect. The probe
checks that rule on every entry of the inventory, and the inventory covers
every seek shape of `lib/`, so the rule holds over the whole tree.

## Scope boundary (what this probe does NOT cover)

* `script-rules:` — its own codec family (the key and the version are
  separated by a newline, not by the `:` slot separator). Listed as an
  explicit exclusion in the inventory, so a *new* uncovered prefix fails the
  completeness check.
* The cursors that do not use the `Letflow.Api.Pagination` codec at all: the
  ledger's `|`-separated key (`lib/letflow/ledger/read.ex`,
  `lib/letflow/ledger/reconcile.ex`) and the exam grading cursor
  (`lib/letflow/modules/exam/grading.ex`). They have no prefix literal and
  no slot list, so the inventory's slot vocabulary does not describe them.
* The seal of the entity-query cursor (`EQ:`): the probe covers its *slot*
  layer (prefix, mint time, token slot), not the AES-GCM seal itself, which
  `Letflow.Entities.Query.CursorSeal` owns.
* The `Letflow.Api.Pagination` page-size validation and the HTTP layer: they
  are covered by `test/letflow/api/pagination_test.exs` and by the route
  tests.

## Non-vacuity

The probe ships a seeded failing case, so it is known to be able to fail:

* `CursorBuilderInventory.broken_decode/3` is the naive split (no slot count)
  that the T-2571 review found. The probe asserts that the round-trip
  property **fails** on it (a `:`-bearing id comes back truncated) while it
  holds for the real codec;
* the structural rule is checked against a seeded broken layout
  (`[:mint, :string, :dt]` — a free string before the last slot), which the
  rule must refuse;
* the completeness check fails when the inventory is empty or when a cursor
  prefix / seek shape of `lib/` is missing from it, so the generated cases
  cannot silently become zero.
