# T-2596 file channel: class table (PILOT G12)

Authority: the G2 authority-rule decision record (option A), decision (c) item 7 and the threat rows S6 and S12, and decision 0094 (the pilot's authority rule, whose rule for the step kinds is the same). One row per case of the file channel; each row names the failing-first test of the case and the class test (the sibling case of the same class that already existed).

Rows R1 (a path-like name at activation) and R9 (the tenant of the row) are the acceptance of gap G12: the file channel writes only inside a tenant-scoped area and a path traversal is impossible.

Rows R2..R6 are the REWORK of the same gap: the refusal of a notification step must reach the caller as a typed 422 on every path that switches a version on (the write, the activate, the reactivate, the rollback and the two promotion paths), and never as a 500. Rows R7 and R8 are the area's own side of the same class: the area enforces the byte cap it publishes on the declared name, and every read path (list, fetch, delete_expired) refuses a prefix that names no tenant with an error tuple instead of a database error.

Every row quotes a sentence of the decision record and names a test that exists in the tree.
