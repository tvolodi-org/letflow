# BA decision: electronics prospect questionnaire and discrete-MES sketch (task T-1821, MES-4)

Business analyst. Owner request 2026-11-12. No issue number was known; the file is named after the task, as `T-1818.md` is. DRAFT design only: no code, no client contact, nothing on production, money, DNS, secrets, demo or a public repository.

## Question

The electronics prospect is unclear. What do we ask on a first call, and what could a discrete MES on Letflow look like while the answers are missing?

## Decision (short)

1. A one-page questionnaire of 16 questions (products, volumes, lines and sites, steps, work orders and routing, BOM and revisions, serials, component-lot traceability, test stations and data, machine connection, rework and scrap, ERP, compliance, shifts, today's pain, decision maker) is in `docs/design/mes/04-electronics-questionnaire-and-sketch.md`, Part A.
2. Three design options are sketched in Part B: (1) lot-level light, (2) serial genealogy with test records, (3) station feed on top of option 2. Each is labelled with the answer that would make it the right one.
3. Per D-120, **every statement about the client's process is labelled GUESS** in the file, each with "answer that would change it" pointing to a question number.
4. Proposed path (a guess-based proposal): option 2 only after questions 7, 8 and 9 are answered; option 3 later; option 1 as fallback if the client has no serials. Nothing is built before the call.

## Reasons

* The owner said only "needs clarification"; so the honest output is questions plus options that depend on the answers.
* The "what Letflow has / lacks" statements are taken from part 1 (T-1818), `docs/design/mes/01-domain-and-fit-gap.md` sections 4 and 5, which records files read in code (serial `tracking_policy`, lot master, ledger with lot in key, codes, process engine; no BOM, work order, routing, serial unit record, station result, inbound device feed).
* Option 3 needs an inbound device interface that Letflow does not have; that is a new credential and a security design, so it is marked as such.
