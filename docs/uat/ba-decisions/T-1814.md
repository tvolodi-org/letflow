### Looked at, nothing new

* **Runbook accuracy.** I extracted every `scripts/...`, `lib/...`, `web/src/...`, `apps/mobile/lib/...`, `config/...` and `priv/...` path quoted in `docs/runbooks/*.md` and tested that it exists. The only misses were `scripts/demo_*_test.exs`, which is the substring of `test/scripts/demo_*_test.exs` (those files exist), and a truncated `scripts/pwa_web_`. No dead path found. I did not compare the runbooks' behaviour statements with the code line by line.
* **Backup and restore.** `docs/runbooks/backup-restore.md` names `scripts/backup/backup.sh`, `restore_test.sh`, `wal_archive.sh`, `retention.conf`; all exist (plus `prune.sh`, `lib.sh`, `manifest.sql`). The retention numbers in the runbook (`DUMP_KEEP_DAYS=14`, `DUMP_KEEP_MIN=7`, `BASE_KEEP=2`, `WAL_KEEP_DAYS=14`) equal `scripts/backup/retention.conf`, and `test/scripts/backup_scripts_test.exs` exists. Its open question 3 (14 days vs. purge) is for the owner.
* **Procurement.** The backend module exists (`lib/letflow/modules/procurement/`, runbook `docs/runbooks/procurement-module.md`) but `web/src/modules/` has no procurement folder. Screens for it would be new product work, and procurement is held by the owner's direction (goal file, 2026-10-31), so not proposed.
* **Exam module UI.** Exam features are D-043 (after core and WMS); not proposed. I opened no exam screen for bugs.
* **Mobile/PWA offline queue.** `apps/mobile/lib/offline/offline_queue.dart` and `offline_sync.dart` have size limits, a "kept for the user" state for refused drafts, a single pass with no double send, and tests in `apps/mobile/test/offline/` for the queue, the sync and the install hint. I read the file headers and the sync loop only; found no gap I can show.
* **Printed documents, accessibility.** I looked for document title or language metadata in `lib/letflow/documents/form_print/pdf.ex` and `renderer.ex` with grep and found none, but the PDF is produced by a render step I did not read, so I cannot claim the PDFs lack it. Not a candidate until someone opens a generated PDF; an operator can do it in a minute.
* **Test speed and CI minutes.** `test-speed-20261111.md` is one day old and `ci-minutes-20261110.md` two days old; a new measurement would repeat them. Only the unapplied manifest rebalance (candidate 1) is left over from them. Proposals 2 to 4 in the CI-minutes note are marked unsafe or unverified there; I did not reopen them, and proposal 5 is paid (owner).
* **Process designer after 3B/3C.** I did not open the designer code this round; no claim made.
