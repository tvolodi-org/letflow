## Reasons

1. The task text names the groups: unwritten UAT scenarios (D-114, backup drill, role sidebar, bell), accessibility
   beyond forms, mobile/PWA follow-ups, designer slice 3, administrator documentation, security self-review. Items 1-3
   cover the scenarios, 4 accessibility, 5 mobile, 6-7 designer, 8 documentation, 9 the bell, 10 the review. The backup
   drill is handled in the owner list above with its reason.
2. Not repeated: T-1518 and T-1551 items (the B2 items are merged; scenarios for them are new work and not a repeat of
   their build), D-114(3)-(5) designs, tenant-creation slices.
3. Ranking: scenarios first (cheap, no decision, they fix the oldest gap, as in T-1518 reason 2), then accessibility and
   mobile (pilot first week), then designer slice 3 (A before B), documentation, the bell requirement, and last the
   large security review, which is mostly reading and should start when the build queue has room for a deep review.
4. Decision-bound parts are separated from the rest so the rest can start.
