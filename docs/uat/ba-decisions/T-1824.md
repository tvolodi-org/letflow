# BA decision T-1824: MES draft roadmap and small pilot

## Question
From MES-1..MES-6, which phases, build tasks (size S/M/L), first demo and "not promised" list make a draft roadmap for a MES on Letflow for chemical plants and an electronics producer?

## Decision
The answer is `docs/design/mes/07-roadmap-and-pilot.md` (draft, options only). Main points:
- Phase 0 (4 to 6 weeks): a demo on existing modules (items, lots, stock documents, locations, codes, process engine with four-eyes, documents, audit) plus three internal proofs, the first being the stock ledger change proof.
- Phase 1 batch record, phase 2 bagging and pallets, phase 3 streams and tanks, phase 4 plant connectors, phase 5 electronics only if the client is real.
- Each phase has build tasks with size, risks and dependencies; section 4.2 lists what is NOT promised (hold enforcement, recipes, automatic consumption, machine data, electronics, legal e-signature, price).

## Reasons
- The plan follows the recommendations already written in parts 2 to 5, so no new design choice was made silently.
- The biggest unknown (ledger policy change) is put first as a proof with a stop rule.

## Sources opened
`docs/design/mes/01` to `06` in this worktree (fit/gap table, effort table, prototype list, recommendations, market note). No web access and no client contact.

## Assumptions (UAT assumption, to be confirmed by the process owner)
- All week and size figures are rough assumptions, not measured; the phase 0 to 3 total (7 to 10 months) is my sum and is wider than part 5's 6 to 8 months.
- A demo on existing modules can be set up in 2 to 3 weeks; not tested.
- The demo uses a fictional plant.

Decision for UAT only; the process owner configures production.
