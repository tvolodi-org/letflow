# iPhone-дағы Letflow: 15 минуттық тест

Көмектескеніңіз үшін рахмет. Қажет: Safari бар iPhone, осы сілтеме және берілген логин.
Сілтеме: @@LINK@@

1. Сілтемені Safari-де ашыңыз (басқа браузерде емес). «Бөлісу», содан соң «Басты экранға» түймесін басыңыз. Letflow-ды жаңа белгішеден ашыңыз.
2. Берілген логинмен кіріңіз. Қолданбаны жапсаңыз, қайта кіру қажет болуы мүмкін; бұл қалыпты жағдай.
3. 3 кодты сканерлеңіз: «Кодты сканерлеу» түймесін басыңыз, сұраған кезде камераға рұқсат беріңіз, кодқа бағыттаңыз. Мұны 3 рет жасаңыз. Камера түймені басқаннан кейін ғана қосылады.
4. Бір дыбыстық жазба жасаңыз: қойма құжатын ашыңыз, «Айту» түймесін басыңыз, микрофонға рұқсат беріңіз, қысқа сөйлем айтыңыз, «Тоқтату және жіберу» түймесін басыңыз.
5. Бір рет офлайн жұмыс істеңіз: «Ұшақ» режимін қосыңыз, қойма құжатының бір жаңа жобасын сақтаңыз. «Байланыс жоқ. Жоба осы құрылғыда сақталды...» деген хабар шығуы керек. «Ұшақ» режимін өшіріп, қолданбаны қайта ашыңыз: жоба қолданба ашылғанда жіберіледі (фонда емес).
6. Пікір жіберіңіз (төменде).
7. Бірдеңе дұрыс болмаса: қадам нөмірін және экранда не көргеніңізді жазып қойыңыз. Экран суреті көмектеседі.
