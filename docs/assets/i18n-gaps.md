# i18n gaps

Keys that still carry their English value in one or more non-English locales.
A key is listed here when its value in `ru` or `kk` matches the English value exactly;
technical terms and codes that are intentionally language-neutral are expected here.

## Mobile

Source: `apps/mobile/lib/i18n/l10n/` (`app_en.arb`, `app_ru.arb`, `app_kk.arb`).
Generated by T-1460. 226 keys total; 3 are still English in both ru and kk.

| Key | English value | Same in ru | Same in kk |
|-----|--------------|-----------|-----------|
| `bootstrap.slugEntry.hint` | `acme` | ✓ | ✓ |
| `codes.kind.epc` | `EPC` | ✓ | ✓ |
| `codes.kind.tid` | `TID` | ✓ | ✓ |

All three are intentionally language-neutral: `acme` is a placeholder slug example,
`EPC` and `TID` are industry acronyms.
