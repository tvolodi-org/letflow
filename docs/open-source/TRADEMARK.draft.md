# Trademark and name policy (DRAFT)

> DRAFT for review by a lawyer; not legal advice; not in force. The permissions below are examples
> only: they depend on the owner's answer to Q5 in `docs/uat/ba-decisions/T-1521.md` (keep the name
> "Letflow"? filing in which countries?). **No trademark search has been made**; check the name for
> clashes before any announcement. "Letflow" is the working name.

## Why a separate policy

The MIT licence (owner decision D-116) gives no right to use the project's names, logos or
brand. The licence covers the code; this note covers the name.

## What is covered

- The name "Letflow" (and any later product name), the logo and the files under `web/public/brand`.
  These files are **not** licensed under the repository licence.
- The names of editions ("Community Edition", "Corporate Edition", final names open).

## Example permissions (to be set by the owner)

| Use | Proposed |
|---|---|
| Say the software is compatible with or based on Letflow, factually | Allowed |
| Unmodified distribution under the name Letflow | Allowed |
| A modified fork or a hosted service using "Letflow" as its own product name or logo | Not allowed without written permission; use a different name |
| "Powered by Letflow" badge | Open question |
| Company or domain names containing "Letflow" | Not allowed without written permission |
| Pilot customers' own names (BilimBaga, Qoimeks, others) | Not part of this policy; never in the public tree (see T-1521 section 5, item 3) |
