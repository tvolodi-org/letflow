# Что изменилось для администраторов компании с 9 ноября 2026 (Русский)

Другие языки: [English](whats-new-en.md) · [Қазақша](whats-new-kk.md). Во всех трёх файлах одни и те же разделы в одном порядке. Основное руководство: [ru.md](ru.md).

Здесь простыми словами перечислено, что нового для человека, который администрирует Letflow в своей компании. Названия меню даны так, как их показывает экран на вашем языке. У каждого нового экрана есть ссылка **Справка** с подробностями.

## 1. Импорт пользователей из файла Excel

В разделе **Администрирование > Пользователи** теперь можно создать сразу много пользователей из файла .xlsx.

* Нажмите «Скачать шаблон», заполните по одной строке на пользователя (имя пользователя, отображаемое имя, e-mail) и сохраните файл.
* Перетащите файл на экран и нажмите «Проверить файл». На этом шаге ничего не сохраняется. Если строка отклонена, причина показана рядом с ней: исправьте её в файле и проверьте снова.
* Когда проверка покажет «Готово к импорту», нажмите «Импортировать пользователей».
* В файле может быть до 200 строк и до 2 МБ. Уже существующий пользователь при импорте никогда не меняется.

## 2. Инструкция по сбросу пароля

На странице пользователя есть кнопка «Отправить инструкцию по сбросу пароля». Она отправляет пользователю письмо с просьбой выбрать на странице входа «Забыли пароль». Пароль вы не видите и не задаёте. Неактивному пользователю и пользователю без e-mail ничего не отправляется.

## 3. Повтор хода экземпляра

На вкладке **Граф** экземпляра можно переключить вид с «Сейчас» на «Повтор». Повтор проходит по пути, который экземпляр действительно прошёл, шаг за шагом, с временем каждого шага. У экземпляров, которые работали до начала записи шагов, повтора нет; вид «Сейчас» для них работает.

## 4. Выкладка версий модулей (только операторы платформы)

Если вы оператор платформы, новый экран показывает, как новая версия модуля по очереди выкладывается на компании, и результат для каждой компании. Выкладку, остановившуюся после нескольких сбоев, можно продолжить, чтобы повторить для компаний с ошибкой. Обычные администраторы компании этот экран не видят.

## 5. Вход для созданных вами пользователей (пока не включён)

У пользователей, созданных на экране «Пользователи» или импортом из Excel, пока нет собственного входа. Кнопка, которая создаст им первый пароль, есть, но **она выключена**: отвечает «недоступно» и ничего не меняет. Повторять нажатие не нужно. Пока владелец платформы её не включил, просите оператора платформы создать вход для каждого нового пользователя, как раньше.

## 6. Длинные списки: «Загрузить ещё» и сообщение «Показаны первые»

Экраны с большим числом записей больше не обрываются молча. Экраны карточек основных средств и кодов загружают списки частями: нажмите «Загрузить ещё» под списком или сузьте его фильтрами и поиском. Экраны позиций, мест хранения и подразделений, а также выпадающие списки на экранах склада и основных средств (позиция, место, сотрудник) теперь читают до 10 000 записей каждого вида, поэтому можно выбрать запись, которая находится далеко в списке. Если список всё же длиннее, сообщение на экране говорит, сколько записей показано и что остальные оттуда недоступны. Увидев такое сообщение, сузьте список фильтрами. Страница **Справка: длинные списки** (`/help/longLists`) объясняет это тремя задачами.
